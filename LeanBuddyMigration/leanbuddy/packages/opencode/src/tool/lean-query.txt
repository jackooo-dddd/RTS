Read-only Lean queries in the context of a project file (its imports, namespaces, `open`s and the declarations before the target theorem).

Commands:
- "check" with a term: `#check (term)` — the term's type. Example: input `Finset.sum_le_sum`.
- "print" with a declaration name: `#print name` — the declaration's statement and, for definitions, its value.
- "search" with a name fragment: declaration names that contain it (case-insensitive; `*` matches any text), shortest first, the first ones with their types. Example: input `sum_le` or `Prosa*service*`.

Parameters:
- `file`: the .lean file whose context to use (defaults to the bound proof file).
- `theorem`: query in the context just before this declaration (defaults to the end of the file).

Notes:
- Queries never change any file and count as lookups, not proof steps.
- Name search matches names only, not statement shapes; follow it with `check` on a candidate before using it.
- For the goals of the current proof use `lean_session`, not `lean_query`.
