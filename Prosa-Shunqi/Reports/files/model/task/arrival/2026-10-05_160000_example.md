### Every difference from official Prosa in the closure

Patches: `Validation/patches/prosa-v06-rocq93-official-proof-closure-common.patch` and
`…-example.patch`. 14 of the 55 files differ; the other 41, including `example.v`, are byte-identical to official
Prosa.

| File | Change | Why |
|---|---|---|
| `util/tactics.v` | `ssreflect.done` → `Corelib.ssr.ssreflect_rw.done` in `Ltac done` | Rocq 9.3 renamed the module that holds the ssreflect `done`, so the old qualified name no longer resolves. The new name is the same tactic. |
| `util/seqset.v` | `Definition set_of of phant T := set.` → `Definition set_of (_ : phant T) := set.` | Rocq 9.3 no longer parses the `of` binder. The new binder is the same anonymous binder. This is the accepted `prosa-v06-rocq93-util-seqset.patch`. |
| 12 files: `util/{unit_growth,list,nondecreasing,sum,bigcat,div_mod}.v`, `analysis/facts/behavior/{arrivals,service,completion,deadlines}.v`, `analysis/facts/job_index.v`, `analysis/facts/model/task_arrivals.v` | One added line after the imports: `Set SsrOldRewriteGoalsOrder.` | Rocq 9.3 ssreflect puts `rewrite` side conditions before the rewritten goal. This documented flag restores the Rocq 9.0 order that the official proof scripts were written for. The flag is file-local, and no proof script is changed. |

**The accepted `util/tactics.v` patch is not used here.** That patch (`prosa-v06-rocq93-util-tactics.patch`) replaced
the reference with a bare `done`. Inside `Ltac done := solve [ done | … ]` a bare `done` names Prosa's `done`
itself, so `by` recurses until `Stack overflow`. This was the original `util/list.v:23` blocker. The fixed
qualified name is used instead, and no accepted artifact changes, because this closure is a separate source tree.
