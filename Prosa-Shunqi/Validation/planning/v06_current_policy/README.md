# 当前 v0.6 翻译政策

本目录是后续翻译的有效表示政策入口，依据固定 Prosa v0.6 源码、已审核的语义关系和已验收的本工作区声明。`representation_policy.md` 与 `foundational_decisions.md` 保留了原批准的 v0.6 语义规则，删除了已无用途的旧版本候选/复用路线；这项整理本身不改变任何 production Lean、证书或验收状态。

`../v06_mapping/` 为历史比较快照，曾被基线审计按整个目录哈希绑定，因此保持原样。新翻译不要读取其旧版本 inventory 或迁移标签来选择实现。当前接受状态以 `../v06_pipeline/` 的有效 machine manifest/status 为准。
